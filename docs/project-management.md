# Organización del trabajo

Este proyecto utiliza una metodología ágil tipo Kanban para organizar las 15 fases de desarrollo.

## Flujo de trabajo

- Backlog: Tareas planificadas a futuro.

- Todo: Tareas priorizadas para el ciclo actual.

- In Progress: Tareas en desarrollo activo (Frontend/Backend).

- Review: Tareas completadas pendientes de validación técnica.

- Done: Tareas finalizadas y verificadas.

## Estructura técnica
- Frontend: React + Vite + TypeScript + Tailwind CSS.
- Backend: Node.js + Express (Arquitectura por capas: Controller-Service-Repository).
- Documentación: Centralizada en /docs.
